## Tracekit: Tamper-Evident Intent-Reasoning-Action Auditing for Autonomous Coding Agents

https://arxiv.org/abs/2609.35659v1

### Claims — model summary, not independent evidence

- Tracekit captures three channels for every agent session: intent, self-report, and actions.
- Tracekit hooks into Claude Code’s lifecycle events and reconstructs multi-agent hierarchies.

### Methods — model summary

- Tracekit uses a hash-chained ledger with external anchoring and a live observer that re-verifies the chain client-side.

### Author-reported evidence — not replicated

- Across 1,600 random mutations, the chain detects every edit, deletion, reordering, forged insertion and torn write; tail truncation and full re-chaining are invisible to the chain alone and are caught only by anchors.
- A hook costs 23.9 ms at the median, flat up to 100,000 ledger records, and the chain stays correct under 16 concurrent writers.

### Limitations — model interpretation

- The system does not claim to read a model’s internal state and treats the self-report as testimony and the executed actions as evidence.
- The evaluation method for agent monitors when real agents rarely misbehave is introduced through seeded-fault splicing.

### Experiments — model proposals, not executed

Comparator: Comparing the gate's effectiveness against a default policy that flags network tools, destructive and side-effecting commands, secrets access, and MCP tools.. Metric: Percentage of harmful tool calls blocked or flagged.. Trial budget: 4 examples per condition; stop after 20 minutes.

## Towards Reliable AI Data Scientists: Data Agents with Workflow Harnesses

https://arxiv.org/abs/2609.35255v1

### Claims — model summary, not independent evidence

- Data Agents are equipped with workflow harnesses to address reliability issues in data science tasks.
- The workflow harness consists of five functional stages: perception, planning, execution, verification, and repair.

### Methods — model summary

- Data Agents infer intrinsic structures and governing properties from heterogeneous sources to achieve deep semantic grounding.
- Data Agents navigate the solution space by decomposing high-level tasks into executable steps and evaluating alternative steps.

### Author-reported evidence — not replicated

- The workflow harness is necessary to achieve reliability in data science tasks and mitigate silent failures.
- Data Agents need routine checking to allow timely inspection of key analytical steps.

### Limitations — model interpretation

- The current paradigm of Data Agents remains insufficient for solving data science tasks reliably.
- Existing works focus on narrow modalities, tasks, or stages of the analytical workflow, with limited integration across the full data analysis process.

## Poster: Towards ProofWeave: A Privacy-Minimised, Integrity-Anchored Evidence Plane for Continuous Agentic Assurance

## EP-Mem: Elastic Privacy Memory for Social Relationship-Aware LLM Agents

https://arxiv.org/abs/2609.35233v1

### Claims — model summary, not independent evidence

- EP-Mem proposes an Elastic Privacy Memory architecture for long-term social interactions, addressing the problem of privacy in LLM agents.
- EP-Mem introduces a token-level memory driven by user-configurable privacy policies, combining default circulation rules with fact-level exceptions.

### Methods — model summary

- EP-Mem aligns privacy governance with memory management by introducing privacy control at the summary, event, and metadata layers.
- EP-Mem uses a pluggable privacy engine to enforce disclosure control throughout the memory lifecycle, including generation, storage, and retrieval.

### Author-reported evidence — not replicated

- Experiments show that EP-Mem achieves 94.0% privacy classification accuracy, improves disclosure-permission judgment from 22% to 68%, and reduces privacy leakage by 75.6%.
- EP-Mem preserves or improves native retrieval performance on both EP-Bench and LoCoMo.

### Limitations — model interpretation

- The paper does not fully characterize the dynamic and context-dependent privacy boundaries through instantaneous interactions.
- The experiments rely on gold evidence for disclosability main results, as native retrieval cannot yet stably recall EP-Bench evidence.

Comparator: Compare the simplified EP-Mem against a baseline system without privacy controls.. Metric: Evaluate the accuracy of privacy classification and the reduction in privacy leakage.. ## ASCT: Attentive Search over Counterfactual Trees for Credit Assignment in Agentic Reinforcement Learning

https://arxiv.org/abs/2609.35215v1

### Claims — model summary, not independent evidence

- ASCT improves mean held-out utility over VinePPO and trajectory-return PPO.
- ASCT-AgentUCT reaches 0.6187 utility, a gain of 0.0248 over VinePPO.

### Methods — model summary

- ASCT uses a framework that turns training-time multi-step search into local action credit.
- ASCT connects counterfactual evaluation to policy learning while deploying the actor alone.

### Author-reported evidence — not replicated

- ASCT-AgentUCT reaches 0.6187 utility versus 0.5939 for VinePPO, with gains in answer F1 and execution cost, and uses 50.3% fewer recorded auxiliary Qwen tokens.
