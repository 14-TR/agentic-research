## Agentic Detection of Online Conspiracies

https://arxiv.org/abs/2609.30250v1

### Claims — model summary, not independent evidence

- Conspiratorial discourse on social media is not always expressed through explicit claims or stable lexical markers.
- The agentic approach achieves the best results compared with both the text-only LLM baseline and the corresponding preloaded-context conditions, improving F1 from 0.535 to 0.730 over the text-only LLM.

### Methods — model summary

- We propose an agentic approach for the detection of conspiratorial discourse, given a specific social media post, the agent can call tools to sample more content from the user, inspect the user’s metadata, query the user’s social circle, or utilize the structure of the social network.
- We evaluate our agentic approach on a unique and challenging dataset of Hebrew tweets, covering 80%–90% of the public Hebrew tweets published over a four-year span (late 2018– early 2023).

### Author-reported evidence — not replicated

- The agentic approach significantly improves the detection of conspiratorial posts, achieving the best results compared with both the text-only LLM baseline and the corresponding preloaded-context conditions.
- Context-aware workflows consistently outperform text-only classification and the agentic framework performs significantly better than other frameworks and settings, including a non-agentic model exposed to the same contexts available to the agent.

### Limitations — model interpretation

- Simply appending all available contexts to every tweet, as part of the input, is neither efficient nor necessarily desirable. Providing excessive contexts may introduce noise and harm performance.
- The agentic framework’s performance may vary across different contexts and tasks, as evidenced by the varying effectiveness of different workflows in interpreting the same text.

## PUBG Ally: A Conversational Embodied Agent as an AI Teammate

https://arxiv.org/abs/2609.29837v1

### Claims — model summary, not independent evidence

- Ally is the first conversational embodied teammate in a commercial live battle-royale game.

### Methods — model summary

- Ally uses a language-model agent that interacts with the game and the player through a bounded tool interface.
- Ally separates deliberate language-model reasoning from fast control through a System 1–System 2 control hierarchy.

### Author-reported evidence — not replicated

### Limitations — model interpretation

## Agent Memory with Episodic Retrieval for Financial Decision-Making

https://arxiv.org/abs/2609.28771v1

### Claims — model summary, not independent evidence

- META is the first cognitive trading framework to embed retrieval-augmented episodic memory directly into the high-frequency decision loop.
- META uses an “Indicator Vector” (e.g., MACD, RSI) to retrieve analogous historical scenarios via cosine similarity.

### Methods — model summary

- META decomposes the trading process into three modular operators: Perception (Φ), Memory (Ψ), and Synthesis (Π).
- META employs a bifurcated state representation that jointly captures symbolic abstractions and numerical microstructure.

### Author-reported evidence — not replicated

- META achieves substantial gains in profitability and stability over stateless baselines, showing that coupling cognition with memory yields agents that not only react to markets—but learn from them.
- META’s memory operator extends dynamic memory principles to structured numerical domains, enabling adaptive reasoning grounded in market feedback.

### Limitations — model interpretation

- META’s memory configuration uses a top-k and similarity-threshold retrieval strategy, which may not always be optimal for all market conditions.
- The evaluation of META is based on a limited set of financial assets, which may not fully represent all market conditions.
