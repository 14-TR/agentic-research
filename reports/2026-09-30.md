## AnyAct: Universal Action for Self-Evolving Agents

https://arxiv.org/abs/2609.37025v1

### Claims — model summary, not independent evidence

- AnyAct addresses the challenges of large-scale, dynamic tool ecosystems by proposing a universal action layer that constructs a self-evolving action space.
- AnyAct demonstrates state-of-the-art performance on LiveMCPBench and achieves 77.27% overall success with only 50 steps on OSMCP.

### Methods — model summary

- AnyAct uses hierarchical progressive retrieval to filter task-relevant actions and test-time reliability evolution to prune unreliable actions.
- The framework includes a heterogeneous observation grounding module that integrates feedback from multiple modalities into a unified knowledge space.

### Author-reported evidence — not replicated

- AnyAct outperforms baseline methods across various LLM base models on LiveMCPBench and achieves significant improvements for models with constrained native capabilities.
- On OSMCP, AnyAct achieves 77.27% overall success with only 50 steps, which is half the steps required by most competitors.

- ToCoMAS improves task success over baselines across backbones.
- ToCoMAS enforces topological coherence, deriving agent responsibilities, required handoffs, and memory boundaries from shared task-and-tool regions.

### Methods — model summary

- ToCoMAS maps an upstream-provided task graph to a public tool graph under global operation and dependency constraints, then groups structurally and operationally compatible regions into reusable agent responsibility domains.

## FOCUS: Training-Free Decision-Preserving Context Compression for LLM Agents

https://arxiv.org/abs/2609.37590v1

### Claims — model summary, not independent evidence

- FOCUS is a training-free, test-time context compression framework.
- FOCUS operates over interaction spans rather than tokens, preserving the structural integrity of agent trajectories.

### Methods — model summary

- FOCUS uses Monte Carlo rollouts of future trajectories to estimate the counterfactual utility of each span.

### Author-reported evidence — not replicated

- FOCUS significantly reduces context footprint while improving task success rates relative to existing compression methods.
