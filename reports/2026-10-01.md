## Can Agents Trust Their Skills? Uncovering Unsafe Chains of Trust in Skill-Based LLM Agents

https://arxiv.org/abs/2609.39065v1

### Claims — model summary, not independent evidence

- TrustProbe identifies 104 taint-style vulnerabilities across 11 open-source agents.
- 25.1% of skill-agent trials exercise the identified vulnerable paths.

### Methods — model summary

- TrustProbe uses source-to-sink analysis to identify paths through which skill content can exercise the agent’s authority.
- TrustProbe applies directed greybox fuzzing, using runtime feedback to select and revise plausible SKILL.md inputs.

### Author-reported evidence — not replicated

- Across 11 open-source agents, eight with more than 10,000 GitHub stars, TrustProbe identifies 104 verified taint-style vulnerabilities spanning command injection, arbitrary file disclosure and tampering, attacker-directed network requests, and code execution.
- When the same skill bodies are delivered as direct prompts, only 33 of the 104 (31.7%) vulnerabilities remain exploitable.

### Limitations — model interpretation

- The study does not classify the original skills as malicious, only demonstrating that existing skill-mediated interactions can carry attacker-controlled content into operations exercised under the agent’s authority.
- The experiments do not involve full training runs or full agent frameworks, focusing on toy tasks or locally available public examples.
